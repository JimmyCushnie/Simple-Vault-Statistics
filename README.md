# Simple Vault Statistics

This is a plugin for [Obsidian](https://obsidian.md) that adds a simple popup with various statistics about the current vault.

![](todo screenshot)


## Usage

After installing and enabling the plugin, you can open the popup with the button in the ribbon, or with the "Show Vault Statistics" command (which you can run from the command palette or by giving it a keyboard shortcut).


## Customizing

You can choose which statistics are shown in the popup in the plugin settings page. You can also choose to treat `.txt` files as notes.
